# aregeo 

![Python Version](https://img.shields.io/badge/python-3.12%2B-blue)
![Package Manager](https://img.shields.io/badge/uv-0.10%2B-purple)
![License](https://img.shields.io/badge/license-MIT-green)

A high-precision geospatial package designed to solve Kenya's informal address problem (*"behind the primary school, off the dirt road"*). 

Instead of relying on ambiguous text descriptions, `aregeo` this package convert, validate, store, search, and verify precise property locations in Kenya.
